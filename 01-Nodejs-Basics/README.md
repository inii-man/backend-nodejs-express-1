# 01 - Dasar-Dasar Node.js 📚

Folder ini berisi contoh-contoh kode dasar Node.js, terutama berfokus pada **fitur ES6** yang sering digunakan serta konsep **Asynchronous Programming**.

Node.js sendiri adalah *runtime* (lingkungan eksekusi) yang memungkinkan kita menjalankan JavaScript di luar browser (seperti di server atau komputer lokal kita). Karena Node.js mengadopsi standar JavaScript modern secara cepat, kita sangat sering menggunakan gaya penulisan **ES6** (ECMAScript 6).

### 📝 Daftar Materi:

1. **`1-es6-basics.js`**
   Menjelaskan perbedaan `var`, `let`, `const`, penggunaan `Template Literal` (Backticks), dan `Destructuring` (memecah objek/array).
   
2. **`2-functions-and-classes.js`**
   Menjelaskan penulisan fungsi modern `Arrow Function` dan penggunaan `Class` dalam OOP JavaScript modern.
   
3. **`3-async-callback.js`**
   Membahas cara Node.js menangani proses yang butuh waktu (asynchronous) menggunakan **Callback**. Dan juga menunjukkan apa itu "Callback Hell".
   
4. **`4-async-promise.js`**
   Membahas **Promise**, solusi dari Callback Hell. Bagaimana membuat dan menggunakan Promise.
   
5. **`5-async-await.js`**
   Membahas sintaks paling modern **Async/Await** yang membuat kode asynchronous terlihat rapi layaknya kode synchronous.

6. **`6-event-loop.js`**
   Menjelaskan secara singkat bagaimana **Event Loop** (Call Stack, Message Queue, Job Queue) mengeksekusi kode di belakang layar.

### 🚀 Cara Menjalankan

Buka terminal, arahkan ke folder ini, dan ketik:
```bash
node 1-es6-basics.js
```
(Ganti `1-es6-basics.js` dengan nama file yang ingin Anda jalankan)
